# Projeto-1-Web-1-
Projeto Web
Como executar
Instale as dependências:
npm install
Inicie o projeto:
npm run dev
Abra no navegador o endereço exibido no terminal, geralmente:
http://localhost:5173
Build de produção
Para gerar a versão de produção:

npm run build
Para visualizar:

npm run preview
